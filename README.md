# Mesa de entrenamiento

Web para practicar One Piece Card Game contra un bot desde el móvil o el navegador: https://tonimas35.github.io/mesa-entrenamiento/

En el iPhone, ábrela en Safari y usa «Compartir → Añadir a pantalla de inicio» para tenerla como una app.

- Las partidas se guardan en el navegador de cada uno. Desde el menú se pueden exportar e importar.
- Es solo para entrenar: no se usa durante partidas de torneo.

Este repositorio solo contiene la app ya compilada. El código fuente está en un repositorio privado.
